# NZLDeobf/vm2 — семпл №2: VM-обфускатор (deobf test, round 2)

Друг переписал обфускатор на **bytecode-VM** (116 опкодов, свой формат, шифрованный блоб).
Спойлер: стало концептуально сильнее, но вывод **опять не работает** — четыре независимых фатальных бага.

## TL;DR

1. **Не парсится** (24 ошибки Luau): эмиттер потерял `",` между блобом и сборкой ключа — строка блоба
   «съела» хвост файла.
2. **`t1` не определена** — финальный стадий дешифровки вообще не эмитнут; краш на первой строке.
3. **Блоб обрезан**: заявлено 80 238 байт нагрузки, в файле 13 493 (16.8%). Оригинал был ~240 КБ.
4. Даже с починками 1–2 (проверено исполнением в настоящем Luau) — падает внутри дешифровки.
   После двух видимых слоёв данные — шум (энтропия 7.987), т.е. `t1` — реальный шифр, не identity.

**Что сделано:** машина вскрыта полностью — формат байткода, все 116 опкодов, крипто-схема, ключ
(17 байт, лежит рядом с блобом). Дизассемблер написан и протестирован. Нагрузка не восстановима из
этого артефакта физически (83% отсутствует + нет кода `t1`) — нужен оригинальный полный файл.

**Главный отчёт с развёрнутыми советами автору:** [VULNERABILITIES.md](VULNERABILITIES.md)
